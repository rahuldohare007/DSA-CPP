## 🧠 Problem-Solving Approach

For each problem, I focus on:

1. Understanding the problem
2. Identifying the pattern
3. Developing a brute-force solution
4. Optimizing the approach
5. Implementing it in C++
6. Analyzing time and space complexity

### Approach

```text
Brute Force
     ↓
Better Approach
     ↓
Optimal Approach
     ↓
Implementation
     ↓
Complexity Analysis
```
